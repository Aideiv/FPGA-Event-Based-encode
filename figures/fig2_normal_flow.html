Fig. 2 VecKM Normal Flow: From Event Neighborhoods to Flow Vectors
The VecKM pipeline transforms raw event data into dense normal flow fields. (1) Each event's k=32 nearest spatiotemporal neighbors are retrieved via spatial hash. (2) A vectorized kernel mixture encodes local geometry into a d=128 descriptor. (3) A 3-layer MLP regresses (vx, vy) flow vectors with per-prediction uncertainty sigma-squared. Diverging flow patterns (red cone) indicate looming objects for collision prediction.
